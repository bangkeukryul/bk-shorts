0. 한눈에 보기

💻 PC (처음 한 번)
GPT-SoVITS 설치 → BK보이스 설치 → 내 목소리 녹음 올리기 → (선택) 학습
📱 휴대폰 (매번)
BK쇼츠 🎙 말하기 → 소재 · 분량 → AI 대본 → 🔊 PC로 내 목소리 만들기 → 사진 · 배경 → 🎬 영상 만들기 → 유튜브 · 릴스 · 틱톡
🌍 외출 중
PC는 집에서 켜 두기 + 휴대폰 · PC에 Tailscale(무료) → 어디서나 같은 방법으로
준비물내용
PC윈도우 10 · 11 + NVIDIA 그래픽카드. RTX 3080 PC로 시작을 추천 (5060은 전용 버전이 따로 있어요)

프로그램GPT-SoVITS (무료 · MIT 라이선스) · BK보이스 (이 설명서에서 받기) · 7-Zip (압축 풀기)
휴대폰크롬 + BK쇼츠 (관리자 미리보기 🎙 말하기 탭)

1. PC 준비 — GPT-SoVITS 설치

이 설명서를 PC 크롬으로 열면 아래 버튼으로 바로 받을 수 있어요. 주소: bangkeukryul.github.io/bk-shorts/voice-guide.html

  1. 그래픽 드라이버 최신으로
    바탕화면 오른쪽 클릭 → NVIDIA 앱(또는 GeForce Experience) → 드라이버 → 업데이트. 없으면 nvidia.com에서 받기.
  2. 7-Zip 설치 (압축 파일 .7z를 풀 때 필요)7-Zip 받기 (64-bit Windows x64)
  3. GPT-SoVITS 통합 패키지 받기 — PC 그래픽카드에 맞는 것 하나만 (파일이 커서 수십 분 걸릴 수 있어요) ⬇ RTX 3080 PC용 (GPT-SoVITS-v2pro-20250604.7z) ⬇ RTX 5060 PC용 (…-nvidia50.7z · 50번대 전용)

    링크가 안 되면 패키지 목록 페이지에서 이름에 v2pro가 들어간 최신 파일을 받으세요. (50번대는 nvidia50이 붙은 것)

  4. 압축 풀기 — 받은 파일 오른쪽 클릭 → 7-Zip → 압축 풀기… → 위치를 C:\ 로.
    폴더 이름을 C:\GPT-SoVITS 로 바꿔 주세요.
    ⚠️ 폴더 경로에 한글 · 띄어쓰기가 없게 해 주세요. (예: C:\GPT-SoVITS ⭕ / C:\내 문서\GPT SoVITS ❌)
  5. 잘 되는지 확인 — C:\GPT-SoVITS 폴더의 go-webui.bat 더블클릭 → 잠시 뒤 브라우저에 GPT-SoVITS 화면이 열리면 성공. 확인했으면 검은 창을 닫아 주세요.

    한글 화면으로 쓰려면 2단계에서 받는 GPT-SoVITS_KO.bat을 쓰면 돼요.

2. PC — BK보이스 설치 · 켜기

BK보이스는 GPT-SoVITS를 휴대폰에서 쉽게 쓰게 해 주는 작은 프로그램이에요. (추가 설치 없음)

⬇ BK보이스 PC 파일 받기 (bkvoice_pc.zip)
  1. 압축 풀기 — 받은 bkvoice_pc.zip 오른쪽 클릭 → 압축 풀기. 안에 4개 파일이 있어요:
    bkvoice.py · BKVoice_start.bat · GPT-SoVITS_KO.bat · README_BKVoice.txt
  2. 4개 파일을 C:\GPT-SoVITS 폴더에 복사 (go-webui.bat이 있는 바로 그 폴더)
  3. BKVoice_start.bat 더블클릭
    파란 창 ‘Windows의 PC 보호’가 나오면 → 추가 정보 → 실행.
    ‘Windows 보안 경고(방화벽)’가 나오면 → 개인 · 공용 네트워크 모두 체크 → 액세스 허용.
  4. 검은 창 확인 — 이렇게 나오면 성공이에요. (처음 켤 때 GPT-SoVITS 준비에 1~3분)
    PIN 번호 : 1234
    휴대폰 : http://192.168.0.10:9870 ← 같은 와이파이

    PIN 번호와 휴대폰 주소를 적어 두세요. 이 창을 닫으면 BK보이스가 꺼져요.

  5. 휴대폰에서 열어 보기 — 휴대폰을 집 와이파이에 연결 → 크롬 주소창에 위 휴대폰 주소 → PIN 입력 → ‘BK보이스’ 화면이 나오면 성공!
💡 PC를 켤 때 BK보이스도 자동으로 켜지게: Win+R → shell:startup 입력 → 열린 폴더에 BKVoice_start.bat의 바로 가기를 넣어 두세요.

3. 바로 써 보기 (학습 없이 5분)

짧은 기준 음성(5~8초) 하나만으로도 비슷한 목소리가 나와요. (학습하면 훨씬 더 닮아요 → 4단계)

  1. 휴대폰 BK쇼츠 → 🎙 말하기 탭 → 맨 아래 🧬 내 목소리 등록 → ❶ 기준 음성 녹음 → 화면 문장을 한 번 읽고 ⏹ → BK보이스_기준음성.wav가 휴대폰 ‘다운로드’에 저장돼요.
  2. 휴대폰 BK보이스 화면(2단계 주소) → ⚙ 설정 → ① 기준 음성 올리기 → 방금 파일 선택 → ✅
  3. 기준 음성에서 읽은 문장 칸에 글자 그대로 입력:
    안녕하세요, 오늘도 쉽고 정확한 소식을 전해 드리겠습니다.
  4. 💾 설정 저장 → 위 대본 칸에 아무 문장이나 넣고 🔊 내 목소리로 만들기 → 들어 보기!
💡 BK쇼츠 PC 주소를 https 주소(6단계 ⑤)로 해 두면, ❶ 녹음 후 💻 PC로 바로 보내기 버튼 한 번으로 올리기 · 문장 입력까지 자동이에요.

4. 내 목소리 학습 (더 똑같이)

GPT-SoVITS 화면은 버전에 따라 글자가 조금 다를 수 있어요. 순서와 위치는 같아요. 3080 기준 전체 30분~1시간.

4-1. 학습용 녹음 만들기 (휴대폰)

  1. BK쇼츠 🎙 말하기 → 🧬 ❷ 학습용 녹음 → ‘읽을 문장 보기’의 20문장을 1~3분 동안 또박또박 (2번 읽으면 더 좋아요) → ⏹ → BK보이스_학습용_날짜.wav 저장
  2. BK보이스 화면 ⚙ 설정 → ③ 학습용 녹음 올리기 → 파일 선택 → PC의 C:\GPT-SoVITS\bkvoice_data\train 폴더로 들어가요.
    (카톡 ‘나와의 채팅’ · USB로 옮겨서 그 폴더에 직접 넣어도 돼요)
조용한 방 · 같은 말투 · 음악/TV 끄기 · 휴대폰은 입에서 한 뼘. 녹음 품질이 곧 목소리 품질이에요.

4-2. GPT-SoVITS로 학습 (PC)

  1. BK보이스 검은 창을 닫아요 (학습할 땐 그래픽카드를 혼자 쓰게)
  2. GPT-SoVITS_KO.bat 더블클릭 → 브라우저에 한글 화면이 열려요.
  3. [0-전처리 데이터셋 획득 도구] 탭
    • 음성 분할: 입력 경로에 C:\GPT-SoVITS\bkvoice_data\train → 음성 분할 켜기 → ‘완료’까지 기다리기
    • 음성 인식: 입력 폴더는 자동으로 채워져요 (output/slicer_opt) · ASR 모델 Faster Whisper · 크기 large-v3 · 언어 ko → 켜기 → 완료
    • (선택) 음성 텍스트 교정: 받아쓰기가 틀린 글자를 고치면 더 좋아요
  4. [1-GPT-SoVITS-TTS] 탭 → *실험/모델 이름에 영어로 myvoice · 모델 버전은 기본(v2Pro) 그대로
  5. [1A-훈련 데이터셋 포맷팅] → 텍스트 주석 파일 output/asr_opt/slicer_opt.list · 오디오 폴더 output/slicer_opt (보통 자동) → 원클릭 실행 → 완료까지
  6. [1B-미세 조정 훈련]
    • SoVITS 훈련: 총 훈련 라운드(total_epoch) 8 → 시작 → 완료
    • GPT 훈련: 총 훈련 라운드 15 → 시작 → 완료

    숫자를 너무 크게 하면 오히려 목소리가 이상해질 수 있어요.

  7. 학습 끝! GPT_weights_v2Pro · SoVITS_weights_v2Pro 폴더에 myvoice… 파일이 생겨요. GPT-SoVITS 검은 창을 닫아요.
  8. BKVoice_start.bat 다시 켜기 → 휴대폰 BK보이스 ⚙ 설정 → ② 학습한 GPT 모델 · SoVITS 모델에서 myvoice(숫자가 가장 큰 것) 고르기 → 💾 설정 저장 → 🔊 테스트

5. 휴대폰으로 쇼츠 만들기 (매번)

  1. BK쇼츠 🎙 말하기 → ① 소재 · 분량 · 채널 이름 · 출처
  2. ② 🤖 AI 요청서 만들기 → 복사 → Gemini/ChatGPT 열기 → 📎 캡처 첨부 + 붙여넣기 → 답 전체 복사 → AI 답 붙여넣기 → ✨ 정리하기
  3. ③ 대본 확인 (✅ ⚠️ 체크 보기 · 숫자는 읽기용 대본에서 한글로)
  4. ④ 💻 내 PC 목소리 → PC 주소 · PIN → 🔊 PC로 내 목소리 만들기
    • https 주소면: 몇 초 뒤 목소리 · 자막이 바로 들어와요 ✨
    • http 주소면: BK보이스 화면이 열림 → 🔊 → 💾 저장 → BK쇼츠로 돌아와 🎧 음성 파일로 불러오기
  5. ⑤ 📺 뉴스 자막 스타일 → 📷 캡처 · 사진 넣기 또는 🖼 배경 자동 만들기 → 🎬 영상 만들기
  6. 완성 MP4 → 유튜브 · 릴스 · 틱톡 앱에서 올리기. 제목 · 설명 · 해시태그는 ③의 ‘📺 올릴 글’에서 복사

6. 외출 중에도 쓰기 — Tailscale (무료)

Tailscale은 내 PC와 내 휴대폰만 안전하게 연결해 주는 무료 프로그램이에요. 공유기 설정이 필요 없어요. (개인 무료 요금제)

  1. PC: tailscale.com/download → Windows 받기 · 설치 → 작업 표시줄 Tailscale 아이콘 → Log in → 구글 계정으로 로그인
  2. 휴대폰: Play 스토어에서 Tailscale 설치 → 같은 구글 계정으로 로그인 → 연결(VPN) 허용 → 켜기
  3. PC 주소 확인: BK보이스를 다시 켜면 검은 창에 http://100.x.x.x:9870 ← Tailscale(외출 중) 줄이 보여요. (휴대폰 Tailscale 앱의 PC 이름 옆 100.으로 시작하는 주소와 같아요)
  4. BK쇼츠 PC 주소에 100.x.x.x:9870 → 이제 LTE · 5G · 다른 와이파이에서도 연결돼요. (휴대폰 Tailscale은 켜 둔 상태)
  5. (추천) https 주소 만들기 → BK쇼츠에서 버튼 한 번에 목소리가 바로 들어와요
    • PC 크롬으로 login.tailscale.com/admin/dns → MagicDNS가 켜져 있는지 확인 → 아래 HTTPS Certificates의 Enable HTTPS 누르기
    • PC에서 Win 키 → cmd 입력 → ‘명령 프롬프트’ 열기 → 아래 줄을 붙여넣고 Enter
      tailscale serve --bg 9870
    • 화면에 나온 https://내PC이름.tail1234.ts.net 주소를 BK쇼츠 PC 주소에 넣기 → 🔗 연결 확인 → ✅
    • 크롬이 ‘로컬 네트워크 기기 액세스’를 물으면 허용
    • 끄고 싶을 때: tailscale serve reset
    ⚠️ Funnel(인터넷 전체 공개) 기능은 켜지 마세요. serve는 내 기기끼리만 보여요.
  6. PC 절전 끄기: 설정 → 시스템 → 전원 → ‘화면 · 절전’에서 절전 모드: 안 함. PC가 잠들면 연결이 안 돼요.

7. 문제 해결

휴대폰에서 BK보이스 주소가 안 열려요
  • PC의 BK보이스 검은 창이 열려 있나요? (닫으면 꺼져요)
  • 주소 끝에 :9870을 넣었나요?
  • 집에서는 휴대폰이 같은 와이파이인가요? 외출 중이면 휴대폰 Tailscale이 켜져 있나요?
  • 방화벽: 윈도우 검색 → ‘방화벽을 통해 앱 허용’ → python의 개인 · 공용 모두 체크
‘PIN 번호가 맞지 않아요’

PC 검은 창 맨 위의 PIN 번호를 넣어 주세요. BK보이스 ⚙ 설정에서 바꿀 수 있어요.

‘GPT-SoVITS가 꺼졌어요’ · 계속 ‘켜는 중’
  • C:\GPT-SoVITS\bkvoice_data\api_log.txt 맨 아래 빨간 오류를 확인해요.
  • RTX 5060 PC는 nvidia50 버전 패키지여야 해요.
  • 그래픽 드라이버를 최신으로 · PC 재시작
  • 폴더 경로에 한글 · 띄어쓰기가 없는지 확인
  • ‘CUDA out of memory’: 게임 · GPT-SoVITS 학습 창 등 그래픽카드 쓰는 프로그램을 닫아요.
목소리가 나랑 안 닮았어요 · 이상해요
  • 기준 음성이 3~10초이고, 읽은 문장을 글자 그대로 적었나요?
  • 4단계 학습을 하고 ⚙ 설정에서 myvoice 모델을 골랐나요?
  • 학습용 녹음을 더 조용한 곳에서, 더 길게(3~5분) 다시 해 보세요.
  • 기준 음성은 영상에서 쓸 말투로 녹음하면 좋아요.
숫자 · 영어를 이상하게 읽어요

BK쇼츠 ③ 읽기용 대본에서 소리 나는 대로 한글로 바꿔 주세요. (예: 2026년 → 이천이십육 년 · AI → 에이아이)

자막이 목소리보다 빠르거나 늦어요

BK보이스로 만든 파일은 문장 시간이 들어 있어 딱 맞아요. 다른 앱의 음성 파일은 쉬는 곳으로 나누니, 문장 사이를 0.5초 이상 쉬어 주세요. ‘화면 자막’과 ‘읽기용 대본’의 줄 수가 같아야 해요.

BK보이스 업데이트는 어떻게 하나요?

이 설명서에서 bkvoice_pc.zip을 다시 받아 C:\GPT-SoVITS에 덮어쓰면 돼요. 설정 · 녹음 · 결과(bkvoice_data 폴더)는 그대로 남아요.

8. 꼭 지킬 것

  • 본인 목소리만 학습하세요. 다른 사람 · 연예인 목소리 복제는 법적 문제가 될 수 있어요.
  • 실제 사람처럼 들리는 AI 음성은 플랫폼 규칙에 따라 ‘AI 생성(합성) 콘텐츠’ 표시를 해 주세요.
  • 언론사 기사 화면 · 사진을 영상에 그대로 쓰면 저작권 문제가 될 수 있어요. 캡처는 대본 재료로, 화면은 내 사진 · 자동 배경 · 공공누리 자료를 쓰세요.
  • 정치 · 경제 소재는 사실 확인 · 출처 표기 필수. 선거 기간에는 선거법 제한도 있어요.
  • BK보이스 PIN 번호는 남에게 알려 주지 마세요. 녹음 · 결과 파일은 내 PC(bkvoice_data)에만 저장돼요.
