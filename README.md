# BK쇼츠 (PWA)

BK톡톡의 가족 앱이에요. 주소: https://bangkeukryul.github.io/bk-shorts/  ·  BK톡톡: https://bangkeukryul.github.io/bk-card/

사진 + 글귀(자막) + 배경음악으로 틱톡 · 유튜브 쇼츠 · 릴스용 **9:16 세로 감성 영상(MP4)** 을
**휴대폰 브라우저 안에서 바로** 만드는 웹앱입니다. 홈 화면에 설치하면 일반 앱처럼 쓸 수 있습니다.

- 서버가 필요 없습니다. 영상 처리는 사용하는 사람의 휴대폰이 직접 합니다 (Canvas + WebCodecs).
- 사진과 음악은 어디에도 업로드되지 않습니다.
- 외부 라이브러리가 없어서, 한 번 열면 오프라인에서도 동작합니다 (글꼴은 처음 쓸 때 한 번 내려받음).

## 기능

| 구분 | 내용 |
|---|---|
| 동영상 | 휴대폰 동영상 추가(5·10·15초·전체), 영상 속 소리 또는 배경음악만 선택 — 영상 소리가 나올 땐 배경음악이 자동으로 쉼 |
| 사진 | 여러 장 추가, 순서 변경, 켄 번스 움직임(줌·패닝), 전환 효과 7종, 가로 사진은 흐린 배경으로 자동 맞춤, 색감 필터 6종 |
| 기본 음악 | 앱이 직접 연주하는 음악 15곡(피아노·기타·스트링·하프·벨·경쾌·팝 비트·로파이·옛 찬송가·이벤트), 픽사베이 무료 음악 찾기 |
| 음악 | MP3·M4A·WAV, BPM 자동 분석 → **박자에 맞춰 사진 전환**, 시작 위치, 볼륨, 끝부분 페이드아웃, 음악 길이에 맞추기 |
| 글귀 자동 | 주제(인생·사랑·행복·위로·감사·가족·우정·옛 성인 명언·성경 말씀)를 누르면 사진 수만큼 자동으로 채움, ChatGPT로 사진 보내 글귀 받기 |
| 내 명함 | 원형 얼굴 사진 + 명함(회사·지점·직함·이름·전화·문구), 처음과 끝 / 계속 / 끝에만 / 안 나옴 — 코드로 그려 글자가 정확함 |
| 글귀 | 한 번에 쓰기(빈 줄로 장면 구분) / 사진마다 쓰기 / TXT·SRT 파일, 위·아래 고정 문구 |
| 글자 | 한글 글꼴 15종 + 내 글꼴 파일, 테두리·그림자·반투명 박스, 등장 효과 5종 (한 줄씩·페이드·타자기·스크롤) |
| 효과 | 하트·별·반짝이·눈·벚꽃·단풍·빛망울·내 스티커 파티클, 도트/화이트/시네마 테두리, 내 PNG 프레임, 비네트, 검은 배경 효과 영상 합성 |
| 앱 공유 | 맨 아래 ‘🔗 주소 · QR코드 보내기’ — 주소·카톡 안내 문구 복사, QR코드 이미지 저장·카톡 보내기 |
| 관리자 | 주소 뒤에 `?bkadmin` 또는 맨 아래 ‘BK Agent · 비케이’ 3초 안에 7번 → 관리용 주소 복사 · 💾 지금 버전 백업(zip) · 되돌리기 안내 (BK톡톡과 켜짐 상태 공유) |
| 결과 | 실시간 미리보기(음악 포함), 1080p/720p MP4 저장, 휴대폰 공유 시트로 갤러리 저장·SNS 바로 올리기 |
| 🎬 영상 편집 (edit.html · 관리자 미리보기) | 동영상 자르기·나누기·순서·속도, 자막 13가지·스티커·가격표·모자이크, 효과·효과음·음악·목소리 녹음, 목적 14가지 템플릿과 오프닝·엔딩 카드, AI 장면 분석 요청서(모아보기 그림), 가게 정보·QR, 세로·가로·정사각 MP4, 블로그 대표 이미지·SRT·글 요청서 |

## 깃허브 페이지로 올리기 (처음 한 번)

1. github.com 로그인 → 오른쪽 위 **+** → **New repository**
   - Repository name: **`bk-shorts`** · **Public** → **Create repository**
2. 새 저장소 화면의 **uploading an existing file** → 이 폴더의 **파일 전부**(폴더 없음)를 선택 → **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **/(root)** → **Save**
4. 1~2분 뒤 주소: `https://bangkeukryul.github.io/bk-shorts/`

### 휴대폰에 앱으로 설치

- **안드로이드 (크롬 · 삼성 인터넷)**: 주소 접속 → 화면 위 **앱 설치** 버튼, 또는 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**
- **아이폰 (사파리)**: 주소 접속 → 아래쪽 **공유** 버튼 → **홈 화면에 추가**

## 고친 파일을 다시 올릴 때

수정한 파일을 저장소에 다시 올린 뒤, **`sw.js`의 `VERSION` 값을 바꿔 주세요** (예: `bk-shorts-v1` → `bk-shorts-v2`).
그래야 이미 설치한 휴대폰도 새 버전을 받습니다. (앱을 한 번 껐다 켜면 적용)

## 지원 환경

| 환경 | 미리보기 | 영상 저장 | 오디오 |
|---|---|---|---|
| 안드로이드 크롬 / 삼성 인터넷 | ✅ | ✅ | AAC (기기가 지원하지 않으면 Opus) |
| 아이폰·아이패드 사파리 (iOS 16.4 이상, 최신 권장) | ✅ | ✅ | AAC (구버전은 무음 또는 Opus) |
| PC 크롬 / 엣지 | ✅ | ✅ | AAC |
| 파이어폭스 | ✅ | 최신 버전만 | Opus |

- 영상을 만드는 동안에는 **화면을 켜 두고 다른 앱으로 넘어가지 마세요.** (휴대폰이 백그라운드 작업을 멈춥니다)
- 오래된 휴대폰에서 1080p가 느리면 **720p**로 만들어 보세요.
- HEIC 사진: 아이폰 사파리는 자동으로 JPG로 바꿔서 넣어 줍니다. 안드로이드에서 HEIC가 안 열리면 JPG로 저장해서 쓰세요.

## 파일 구성

```
index.html            화면
style.css             디자인
app.js                화면 동작 (설정, 미리보기, 저장, 설치)
engine.js             렌더링 엔진 (사진 연출, 자막, 파티클, 박자 분석, 인코딩)
mp4mux.js             MP4 파일 만들기 (H.264 + AAC/Opus)
samples.js            "샘플로 체험하기" 예시 사진·음악 생성
edit.html · edit.css  🎬 영상 편집 화면
ed-core.js            영상 편집: 목적 템플릿 · 자료 · 저장(이어서 하기)
ed-render.js          영상 편집: 그리기 · 자막 · 카드 · 효과음 · 소리 섞기 · MP4 · 모아보기 그림
ed-ui.js              영상 편집: 화면 동작 · AI 요청서 · 블로그 묶음
sw.js                 오프라인 캐시 (서비스 워커)
manifest.webmanifest  앱 설치 정보 (이름, 아이콘, 색)
icon-*.png, apple-touch-icon.png  앱 아이콘
```

앱 이름을 바꾸려면 `manifest.webmanifest` 의 `name`, `short_name` 과 `index.html` 의 `<title>`, `<h1>` 을 고치면 됩니다.

## 음원 저작권 안내

유명 가요를 넣어 SNS에 올리면 음소거되거나 저작권 신고를 받을 수 있습니다.
무료 음원을 쓰거나, 음악 없이 만든 뒤 틱톡·유튜브 앱 안에서 음악을 붙이는 방법을 권장합니다.
